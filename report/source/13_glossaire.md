# Glossaire et acronymes {-}

:::glossaire
**AIC** : critère d'information d'Akaike. Compare des modèles ajustés en pénalisant leur nombre de paramètres.

**API** : interface de programmation (*Application Programming Interface*). Ensemble d'opérations par lesquelles un programme en utilise un autre ; ici, l'interface entre le tableau de bord et les résultats.

**AUC** : aire sous la courbe ROC. Probabilité qu'un cycle critique reçoive un score supérieur à celui d'un cycle normal.

**C-MAPSS** : *Commercial Modular Aero-Propulsion System Simulation*. Simulateur de turboréacteur de la NASA qui a produit le jeu de données.

**Censure à droite** : observation d'une durée de vie seulement minorée, parce que l'unité fonctionne encore à la fin de l'observation.

**FMDS** : fiabilité, maintenabilité, disponibilité et sécurité.

**GroupKFold** : validation croisée dans laquelle toutes les observations d'un même groupe (ici, d'un même moteur) restent dans le même pli.

**HI** : indicateur de santé (*health indicator*). Grandeur scalaire qui résume l'état de dégradation d'un moteur.

**HPC** : compresseur haute pression (*high pressure compressor*), composant dont la dégradation est simulée dans FD001.

**KS** : test de Kolmogorov-Smirnov. Test d'adéquation d'un échantillon à une loi.

**LSTM** : *Long Short-Term Memory*. Réseau de neurones récurrent capable d'exploiter des dépendances temporelles longues.

**MAE** : erreur absolue moyenne.

**MCO** : moindres carrés ordinaires.

**MDT, MUT** : durées moyennes d'indisponibilité et de disponibilité (*mean down time*, *mean up time*).

**MTBF** : durée moyenne entre deux défaillances (*mean time between failures*).

**MTTF** : durée moyenne de fonctionnement avant défaillance (*mean time to failure*).

**MTTR** : durée moyenne de réparation (*mean time to repair*).

**MV** : maximum de vraisemblance.

**PHM** : *prognostics and health management*. Discipline qui regroupe la surveillance de l'état de santé et le pronostic de défaillance.

**RMSE** : racine de l'erreur quadratique moyenne.

**ROC** : courbe caractéristique de fonctionnement d'un classifieur (taux de vrais positifs en fonction du taux de faux positifs).

**RUL** : durée de vie résiduelle (*remaining useful life*), nombre de cycles restant avant la défaillance.

**Score NASA** : métrique asymétrique du challenge PHM, qui pénalise davantage les prédictions tardives.

**SVM** : machine à vecteurs de support.

**Weibull 2P, Weibull 3P** : lois de Weibull à deux et à trois paramètres (forme, échelle et position).
:::
