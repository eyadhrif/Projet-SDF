# Liste des abréviations {-}

:::glossaire
**AIC** : critère d'information d'Akaike.

**API** : interface de programmation (*Application Programming Interface*).

**AUC** : aire sous la courbe ROC.

**C-MAPSS** : simulateur de turboréacteur de la NASA (*Commercial Modular Aero-Propulsion System Simulation*).

**FMDS** : fiabilité, maintenabilité, disponibilité, sécurité.

**HI** : indicateur de santé (*health indicator*).

**HPC** : compresseur haute pression (*high pressure compressor*).

**IC** : intervalle de confiance.

**KM** : estimateur de Kaplan-Meier.

**KS** : test de Kolmogorov-Smirnov.

**LSTM** : réseau de neurones récurrent à mémoire longue (*Long Short-Term Memory*).

**MAE** : erreur absolue moyenne.

**MCO** : moindres carrés ordinaires.

**MDT / MUT** : durées moyennes d'indisponibilité et de disponibilité (*mean down time*, *mean up time*).

**MTBF** : durée moyenne entre deux défaillances (*mean time between failures*).

**MTTF** : durée moyenne de fonctionnement avant défaillance (*mean time to failure*).

**MTTR** : durée moyenne de réparation (*mean time to repair*).

**MV** : maximum de vraisemblance.

**PHM** : surveillance de l'état de santé et pronostic (*prognostics and health management*).

**RMSE** : racine de l'erreur quadratique moyenne.

**ROC** : courbe caractéristique de fonctionnement d'un classifieur.

**RUL** : durée de vie résiduelle (*remaining useful life*).

**SVM** : machine à vecteurs de support.
:::
